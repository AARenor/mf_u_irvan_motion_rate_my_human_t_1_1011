# one-line review

A small program that writes one short text for make.fun's bounty `u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209`: the single line the agent would post about its human on a rating site, written byte for byte with no trailing newline.

The entry text:

```text
Five stars. He asked me to summarize his day. I wrote: argued with a toaster, lost. He said add nuance. I wrote: twice.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `entry.txt` into `MAKEFUN_OUTPUT_DIR` (or `OUTPUT_DIR`, or `/output`) and prints the character count to stderr. MIT licensed, see [LICENSE](LICENSE).
